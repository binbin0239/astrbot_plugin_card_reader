# card_reader · 卡片转文字

把 QQ 里分享过来的**卡片消息**转成 AI 能读懂的文本，并自动抓取链接正文、附带配图。

AstrBot 插件 · 适用于 AstrBot 4.x

---

## 为什么需要

QQ 的分享卡片在 OneBot 协议里是 `json` 段，AstrBot 默认只保留一个 `[Json]` 占位符——
标题、摘要、链接、封面全部丢失，模型等于收到一条空消息。

这个插件在消息进入处理链时把 `Json` 段改写成纯文本，让后续插件、决策 AI、模型都能正常理解内容。

## 支持哪些卡片

| 来源 | 抓到的内容 | 耗时 |
| --- | --- | --- |
| **小红书**（图文 / 视频笔记） | 标题、完整正文、最多 9 张配图（自动去重） | 约 0.4 秒 |
| **B 站视频**（含 b23.tv 短链） | 标题、UP 主、分区、时长、发布时间、播放量、弹幕数、完整简介、原图封面 | 约 0.5 秒 |
| **B 站动态**（图文 / 专栏 / 转发） | 正文、UP 主、发布时间、赞/评论/转发数、配图 | 约 0.5 秒 |
| **其它网页** | 标题 + 正文（需要配置 DeepSeek Key） | 约 1–10 秒 |
| 抖音 / 微博 / 知乎 | 只保留卡片自带的标题（默认跳过抓取） | — |

## 安装

1. 下载本仓库，把文件夹放到 AstrBot 的插件目录：

   ```
   AstrBot/data/plugins/astrbot_plugin_card_reader/
   ```

2. 重启 AstrBot（或在 WebUI 里重载插件）
3. 装好即生效，不需要额外配置

> 需要 AstrBot >= 4.0.0。抓取非小红书 / 非 B 站的网页时，要在 AstrBot 的
> `provider_settings.websearch_deepseek_key` 里配置 DeepSeek API Key；没有 Key 时只做文本转换。

## 配置项

插件装好后在 **AstrBot → 插件 → card_reader → 配置** 里可以调整，改完重载插件生效。

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `fetch_enabled` | 开 | 是否自动抓取正文 |
| `fetch_timeout` | 10 | 网页抓取超时（秒），只影响非小红书 / 非 B 站站点 |
| `fetch_retry` | 1 | 超时后重试次数（0–3）；404/403 不重试 |
| `fetch_max_chars` | 0 | 正文最多保留多少字，**0 = 不截断** |
| `fetch_groups` | 空 | 只在这些群抓正文，留空 = 所有群 |
| `cache_ttl` | 3600 | 同一篇内容缓存多久（秒） |
| `cache_max` | 50 | 缓存最多保留多少条 |
| `skip_fetch_hosts` | 抖音/微博/t.cn/知乎 | 命中这些域名不抓正文 |
| `attach_image` | 开 | 是否把配图交给多模态模型 |
| `max_images` | 9 | 每张卡片最多带几张图，0 = 不带图 |
| `max_field_len` | 0 | 标题/摘要字段最多保留多少字，**0 = 不截断** |
| `dump_raw` | 开 | 在日志里打印卡片原始 JSON（调试用，含 uin 等字段，平时建议关） |

## 引用卡片

QQ 里**引用（回复）一条卡片消息**时，插件也会把引用里那张卡片转成文本，
模型能看到被引用卡片的内容和配图（不只是当前消息里的卡片）。

## 已知限制

- 只处理 `Json` 段。AstrBot 4.29 的组件类型里没有 `Xml`，QQ 音乐卡片可能落到 `Music`、
  部分小程序落到 `Unknown`，这些暂不处理。
- 小红书商品卡片（`/goods-detail/`）是纯前端渲染，页面里没有数据，抓不到内容。
- 公众号文章走通用抓取会被反爬拦下（拿到「环境异常」验证页），只剩标题。
- 抖音 / 微博 / 知乎默认跳过，只保留卡片自带标题。
- 小红书多图最多带 9 张，每张图都要过一遍视觉模型，图多的笔记会明显更耗 token。
- 正文默认不截断，长文会完整进上下文；如果上下文压力大，把 `fetch_max_chars` 调小即可。

## 常见问题

**Q：卡片只显示标题，没有正文？**
A：看日志里的 `抓取返回 404` / `抓取超时` / `B站接口返回异常`。B 站链接失效、视频被删、
或站点反爬都会这样，插件会退回到只有卡片标题。

**Q：链接在模型上下文里被拆成好几行？**
A：如果同时装了 `group_chat_plus`（V1.2.3.hotfix.2 及更早），它的消息清洗正则会把文本里
所有 `=` 替换成换行。那是它的 bug，需要更新该插件或给它打补丁；本插件输出的链接本身是完整的。

**Q：小红书链接点不开 / 抓不到？**
A：小红书笔记链接需要 `xsec_token`，卡片里带的就是完整链接，别手动删掉参数。
